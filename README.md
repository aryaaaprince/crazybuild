# Prince Builders

Full-service construction + retailer marketplace site for Prince Builders.

## What's in this repo
- `index.html` — the complete site: hero, path chooser (retailer marketplace vs full-service build), material catalog, budget tiers, team section, and a two-mode cost calculator (Buyer wizard + Developer rate-editing panel).
- `SETUP.md` — step-by-step: connect Supabase (so rate/retailer edits actually save), then deploy.

## Status
- Frontend: complete.
- Backend: not yet connected — see SETUP.md. Until Supabase is wired up, rate/retailer edits will not persist between visits.

## Local preview
Just open `index.html` in a browser — no build step needed, it's plain HTML/CSS/JS.
